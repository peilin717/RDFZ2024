# Web 资源加载优化与验证

对照版本：`1c8b1dc`。测试日期：2026-10-03。

## 修改

- 128 张 PNG 生成全尺寸 WebP，quality=90；保持原始宽高和透明通道。原始 PNG 不删除。
- 角色图另生成最大 320×400 的缩略图，quality=86，仅用于图鉴、编队列表及队伍小头像。详情、选中编队位置、战斗与剧情保留全尺寸图。
- `.hidden` 使用 `display:none`，开始界面隐藏战场，阻止隐藏页面的背景图请求。
- 图鉴和编队使用 IntersectionObserver，进入可见范围后加载，最多 4 个受控图片任务并行。初次打开桌面图鉴只加载 8/32 张卡片；队伍小头像另按需请求。
- 剧情加载当前画面，成功后最多预取下一张；省流量及 2G 连接不预取。不会预载整个章节或全部角色。
- 详情、剧情提供加载状态及失败重试，防止快速切换时旧图片覆盖新图片。
- 内容哈希命名 WebP；Vercel 配置一年不可变缓存。HTML/JS/CSS 重新验证，避免更新后继续使用旧清单。
- 无依赖 Node 构建只复制入口文件及 WebP 到 `dist`。本次发布目录 53.67 MiB，不包含原始 PNG 和开发工具。

## 下载量

桌面 Chromium，1440×900，全新浏览器上下文。本表统计 Resource Timing 的 `encodedBodySize`，不含 HTML 文档、HTTP 头；使用同样的“开始界面 → 进入主页并跳过教程 → 打开图鉴”流程，不滚动图鉴。主页、图鉴均为从首次访问开始的累计下载量，不是每次切换的增量。

| 场景 | 原版 | 优化后 | 减少 |
|---|---:|---:|---:|
| 开始界面 | 5.899 MiB | 0.283 MiB | 95.2% |
| 主页（包含首次教程） | 8.532 MiB | 1.560 MiB | 81.7% |
| 首次打开图鉴 | 74.242 MiB | 2.037 MiB | 97.3% |
| 全部图片（优化后包含缩略图） | 285.30 MiB | 53.37 MiB | 81.3% |

开始界面图片请求由 3 个变为 0 个。玩家未进入的页面和章节不会因其存在于代码中而下载图片。

## 限速首屏对比

本地静态服务，Chromium CDP 模拟 10 Mbps 下载、80 ms 延迟，原版和优化版各 3 次独立冷启动，取中位数。下载时间是最后一个初始资源的 `responseEnd`，不包含人为等待 networkidle 的 500 ms；它不是 LCP 或“玩家能开始操作”的时间。

| 指标 | 原版 | 优化后 | 减少 |
|---|---:|---:|---:|
| 首屏总下载（含 HTML） | 6,202,621 B | 313,364 B | 95.0% |
| 首屏资源下载完成 | 5.355 s | 0.627 s | 88.3% |
| DOMContentLoaded | 1.092 s | 0.635 s | 41.9% |

这是同条件本地对比；真实 Vercel 表现还取决于区域网络、CDN、HTTP 压缩、设备和缓存。未将模拟结果表述为线上实测。

## 画质

- 128/128 张全尺寸图片保持原始分辨率。
- 128/128 张全尺寸图片的 alpha 通道逐像素一致。
- 在深色背景合成后，以 11×11 均值窗口计算亮度 SSIM：平均 **0.99505**，最低 **0.98951**。SSIM 不是无损保证；WebP 色彩仍采用有损编码。
- 检视了图鉴、角色详情、战斗与剧情截图，文字继续由 HTML 渲染。
- 仅全尺寸 WebP 合计 48.96 MiB，新增缩略图约 4.41 MiB。

## 服务端到浏览器验证

测试分别针对源目录及独立构建的 `dist` 目录。静态服务无业务后端，主要验证发布产物可访问、资源引用有效、游戏逻辑和本地持久化正常。

通过的检查：

- 全部 225 个 WebP URL 返回 HTTP 200，MIME 为 `image/webp`。
- 开始界面没有图片请求；图鉴滚动后加载后续卡片，详情加载全尺寸图。
- 十连招募、自动编队、进入战斗、普通攻击后敌方回合、暂停/恢复。
- 保存返回主页并重新加载后，伙伴、编队和货币数据一致。
- Boss 立绘、战败立绘、后期剧情画面切换、篮球、图书排序、游魂场景、跑酷入口及退出。
- 注入图片请求失败后出现重试，恢复网络后重试成功；快速切换详情不会显示旧图。
- 手机触控视口打开图鉴与角色详情。
- 另以 3 Mbps、120 ms 延迟跑通开始、图鉴、详情、招募、编队和战斗；省流量模式下不发起预取请求。
- 正常测试流程无 JavaScript 异常或 HTTP 4xx/5xx。

这是关键流程及代表性玩法回归，不代表逐关通关全部剧情。Vercel 配置已准备好，但尚未执行真实部署；CDN 响应头需要部署后再验证。

## 复现

安装测试依赖（生产构建不需要这些依赖）：

```bash
python3 -m pip install playwright Pillow numpy scipy
# 已有 Chromium 时使用 --browser 指定路径。
```

启动发布产物服务后：

```bash
python3 tools/test_web.py --url http://127.0.0.1:4173 --browser /usr/bin/chromium
python3 tools/check_web_quality.py
```

将对照提交的 `RDFZ` 单独放到另一目录并启动于 4174，再比较冷启动：

```bash
python3 tools/benchmark_web.py --before http://127.0.0.1:4174 --after http://127.0.0.1:4173 --runs 3
```
